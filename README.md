# 모두의 디자인 실험실

> 다양한 사람의 마음을 생각하고, 누구나 편리한 물건을 다시 디자인해 보자!

초등학교 5~6학년 **Ⅲ. 발명과 융합교육 · 12. 감성을 담은 유니버설 디자인**(1~4차시, 160분) 수업용 반응형 웹앱입니다.
로그인·서버·유료 API 없이 브라우저만으로 동작하며, 태블릿 터치·키보드 조작을 지원합니다.

## 활동 흐름

| 차시 | 화면 | 내용 |
|---|---|---|
| 1~2차시 | 1. 디자인 발견 | 원래 디자인 예시 3종(수업용 가상 예시), 유니버설·감성 디자인 뜻 |
| | 2. 사용자 상황 | 상황 카드 10종(일·환경 중심), 직접 확인/예상 구분 |
| | 3. 디자인 실험실 | 안내판·공용 버튼·공용 수납함 — 요소 5개씩 실시간 조절, 처음/개선 디자인 저장 |
| | 4. 비교 | 나란히 비교, 달라진 요소 자동 표시, 관찰 과제, 근거 기록 (점수 판정 없음) |
| | 5. 발명 아이디어 | 대상 물건 선택, 문제 정의 문장 만들기, 아이디어 카드 비교·선택, 아이디어 카드 인쇄 |
| 3~4차시 | 6. 설계 | 기능·디자인 요소·사용 순서·재료, 설계도 그림판(펜/지우개/도형/이름표/되돌리기) + 글 설명 |
| | 7. 제작 기록 | 제작 상태(자동 완료 없음), 과정·변경점, 선택 사진, 체크리스트 |
| | 8. 사용성 평가 | 평가 방법, 5개 점검 항목(잘됨/보완 필요/확인 못함 — 기본값 확인 못함), 친구 의견·개선 |
| | 9. 전시회 | A4 보고서 인쇄(PDF 저장), JSON 내보내기/불러오기, 친구 평가표·학생 활동지 인쇄 |

## 저장

- 글과 선택값은 `localStorage`, 설계도·사진은 `IndexedDB`에 자동 저장됩니다(이 기기·이 브라우저만).
- 여러 활동을 따로 보관하고 처음 화면에서 골라 이어 할 수 있습니다.
- 다른 기기로 옮길 때는 9단계의 **활동 내용 파일로 저장하기(JSON)** 를 사용하세요(그림 포함).
- 개인정보를 수집하지 않으며 서버로 아무것도 보내지 않습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정).
`dist/`는 상대 경로로 빌드되므로 어떤 정적 호스팅에도 올릴 수 있습니다.

## 기술 스택

React 18 + TypeScript + Vite. 미리 보기는 모두 SVG로 직접 그려 외부 이미지가 필요 없고, 인쇄·PNG 저장 시에도 선명합니다.
