# 자연 모방 발명 연구소

> 자세히 보면, 자연 속에 새로운 생각이 보여요.

초등학교 5~6학년 **Ⅲ. 발명과 융합교육 · 13. 자연에서 발견하는 발명 아이디어**(4차시, 160분) 수업용 반응형 웹앱입니다.
로그인·서버·유료 API 없이 브라우저만으로 동작하며, 태블릿 터치·펜·마우스·키보드를 모두 지원합니다.
개발 명세서: [`docs/13-nature-invention-lab-spec.md`](docs/13-nature-invention-lab-spec.md)

이 앱의 주인공은 발명품이 아니라 **자연을 자세히 바라보며 자신의 생각을 발견하는 학생**입니다. 점수·순위·완성도 경고가 없고, 관찰과 사례 탐구만 하고 끝내도 수첩을 저장·인쇄할 수 있습니다.

## 설치 · 실행 · 빌드

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리 보기
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정).
`dist/`는 상대 경로로 빌드되므로 어떤 정적 호스팅에도 올릴 수 있습니다. 한 번 연 뒤에는 서비스 워커 덕분에 인터넷 없이도 다시 열 수 있습니다.

## 학교 수업에서 쓰는 방법

- **1~2차시:** 표지 → 관찰 01·02(실물 자연물과 돋보기를 함께) → 탐구 03 → 탐구 04 → 모아보기에서 공유. 왼쪽(모바일은 위쪽) 책갈피로 원하는 쪽을 바로 열 수 있어, 첫 시간에 조합·스케치로 서두르지 않게 진행할 수 있습니다.
- **3~4차시:** 모아보기로 지난 기록 회상 → 탐구 05 → 조합 06 → 표현 07 → 모아보기에서 인쇄.
- **기기가 부족할 때:** 모아보기 → ‘골라서 인쇄하기’ → **자연물·생활용품 카드 인쇄**로 종이 카드를 만들어 같은 활동을 할 수 있습니다.
- 자세한 차시별 진행표, 준비물, 유의점은 앱의 **선생님 안내**에 있습니다.

## 저장과 개인정보

- 글과 선택값은 `localStorage`, 그림 선 데이터와 사진은 `IndexedDB`에 자동 저장됩니다(이 기기·이 브라우저만). 상단에 ‘저장 중… → 이 기기에 저장했어요’가 표시되고, 저장할 수 없는 브라우저(개인정보 보호 모드 등)에서는 경고가 나옵니다.
- 새로고침해도 마지막 쪽과 입력값이 남습니다. ‘새 탐험 시작’으로 기록을 지울 때는 확인과 함께 JSON 백업을 권합니다.
- 기기를 옮길 때는 **기록 내보내기(JSON, `schemaVersion: 1`)** 파일을 표지의 ‘다른 기기에서 만든 기록 불러오기’로 가져옵니다. 형식이 맞지 않는 파일은 거부하며 기존 기록을 덮어쓰지 않습니다.
- 실명·학교명·위치를 수집하지 않습니다. 첨부 사진은 형식(JPG/PNG/WEBP)·크기(15MB)를 검사한 뒤 캔버스로 다시 그려 저장하므로 촬영 위치(EXIF) 정보가 남지 않습니다.

## 콘텐츠와 주의사항

- 도감·사례 그림은 모두 **직접 제작한 SVG 개념 삽화**이며 ‘실제 현미경 사진’이 아님을 화면에 표시합니다. 외부 이미지·폰트에 의존하지 않습니다.
- 필수 사례 4종(도꼬마리→찍찍이, 연잎→발수 표면, 벌집→허니컴 경량 패널, 솔방울→습도 반응 구조 연구)과 비교용 상상 사례 2종(민들레 씨앗↔낙하산, 깃털↔지퍼)을 담았습니다. 비교용 사례는 발명 기원이 아님을 명시합니다.
- **출처 검수 필요:** 사례 데이터의 `sourceUrl`은 모두 `null`입니다(출처를 지어내지 않음). 정식 배포 전 검증한 출처를 `src/data/biomimicryCases.ts`에 입력해 주세요. 선생님 안내의 ‘콘텐츠 검수 목록’에 표시됩니다.

## 남아 있는 제한사항

- 브라우저 저장소를 지우면 기록도 사라집니다(서버 없음). 중요한 기록은 JSON 내보내기나 인쇄로 보관하세요.
- 개인정보 보호 모드 등 IndexedDB를 쓸 수 없는 환경에서는 그림이 창을 닫을 때까지만 유지됩니다(화면에 안내 표시).
- 관찰 퀴즈, 종이 콜라주, 교사용 목록 편집(명세 P1·P2 일부)은 구현하지 않았습니다.

```text
├── components/
│   ├── NotebookCover.tsx      # 표지 · 목차
│   ├── NatureAtlas.tsx        # 관찰 01 도감 · 관찰 02 관찰 수첩
│   ├── Magnifier.tsx          # 확대경
│   ├── FeatureExplorer.tsx    # 탐구 03
│   ├── CaseMatching.tsx       # 탐구 04
│   ├── CaseMuseum.tsx         # 탐구 05
│   ├── CombinationDesk.tsx    # 조합 06
│   ├── Sketchbook.tsx / SketchCanvas.tsx   # 표현 07
│   ├── NotebookView.tsx       # 모아보기 · A4 인쇄 화면
│   ├── TeacherGuide.tsx       # 선생님 안내
│   └── Diagrams.tsx, ui.tsx
├── data/                      # natureItems, biomimicryCases, householdObjects, pages
├── storage/                   # model(타입·검증), storage(localStorage·IndexedDB·JSON)
└── styles/                    # theme.css, print.css
```
