# 13. 자연에서 발견하는 발명 아이디어 — 「자연 모방 발명 연구소」 웹앱 개발 명세서

> **개발 지시문(필독)**  이 문서를 바탕으로 초등학교 5~6학년이 수업에서 실제 사용할 수 있는 **완성형 한국어 반응형 웹앱**을 만든다. 클릭만 가능한 목업, 정적인 슬라이드, 의미 없는 가짜 데이터 입력 화면으로 끝내지 않는다. **자연물 관찰 → 특징 기록 → 자연 모방 사례 탐구 → 자연물과 생활용품 카드 조합 → 아이디어 스케치 → 탐구 수첩 출력**이 실제 작동해야 한다.
>
> **수업 설계의 핵심:** 학생에게 발명품을 반드시 만들어 내라고 요구하지 않는다. **1~2차시는 자연물 관찰과 기존 사례 탐구에 충분히 집중**하고, **3~4차시는 자연의 특징과 익숙한 물건을 자유롭게 결합하여 그림·글로 표현**한다. 결과물은 완성된 발명품이 아니라 `자연 관찰 기록 + 자연 모방 사례 탐구 + 자유로운 조합 스케치`이다.
>
> **시각적 차별화:** 11번 「우리 동네 발명 지도」의 밝은 지도·카드형 UI, 12번 「모두의 디자인 실험실」의 조절 패널·디자인 대조 UI를 **복제하지 말 것**. 13번은 **야외 탐험대의 낡지 않은 식물도감·탐사 수첩·종이 콜라주**를 모티프로 한다. 자세한 스타일 시스템은 6절을 따른다.

| 항목 | 내용 |

| 학생에게 보이는 부제 | **자세히 보면, 자연 속에 새로운 생각이 보여요** |

| 3~4차시 공부할 문제 | 자연의 특징을 기존 물건과 결합하여 새로운 아이디어를 표현해 봅시다. |
| 핵심 학습 경험 | **발견 → 자세히 관찰 → 닮은 점 찾기 → 원리 연결 → 뜻밖의 조합 → 상상 표현 → 공유** |
| 수업 산출물 | 자연 관찰 기록지, 자연 모방 발명 사례 탐구 기록, 아이디어 조합 스케치 |
| 기기 | 태블릿, 교실 PC, 노트북; 터치/펜/마우스/키보드 지원 |
| 운영 기본값 | 로그인 없음, 유료 API 없음, 학교 주소·실명·정확한 위치 불필요, 기기 내 자동 저장, A4 출력 지원 |
| 성격 | 탐구 보조 웹앱. 실물 관찰, 질문, 교실 대화를 돕되 **대체하지 않음** |

### 대상 학생에게 제시할 메시지

- `멋진 발명품을 꼭 만들 필요는 없어요.`
- `자연을 오래 바라보고 새롭게 발견한 사실만으로도 훌륭한 탐구예요.`
- `익숙한 물건에 자연의 특징을 더해 보세요. 이상한 조합도 괜찮아요!`
- `정답보다는 “왜 그렇게 생각했는지”가 중요해요.`

### 꼭 지켜야 할 교육적 원칙

1. **관찰의 충분성:** 1~2차시 전체에서 관찰·비교·사례 탐구가 중심이며, 발명품 구상을 앞당겨 강요하지 않는다.
2. **발견과 추리 구분:** `내 눈으로 확인했어요`, `사진/영상에서 보았어요`, `이렇게 생각해요`를 구별한다. 추리를 자연과학의 확인된 사실로 표시하지 않는다.
3. **자연의 구조와 기능 연결:** 색깔·생김새뿐 아니라, 특정 구조가 어떤 역할을 하는지 질문한다.
4. **모방과 상상 구분:** 실제 자연 모방 기술 사례와 학생이 자유롭게 상상한 연결을 다르게 표시한다.
5. **제작·성능 점수 강제 금지:** 완성품 제작, 비용 계산, 등수, 특허 가능성, 자동 품질 점수는 수업 목적에 맞지 않으므로 기본 기능에서 제외한다.
6. **온라인 자료 정확성:** 자연물과 기술의 관계를 과장하거나 역사적 기원을 단정하지 않는다. 정식 사진 사용 시 출처·라이선스를 확인한다.
7. **디지털과 실물의 조화:** 앱만 사용해도 과제를 수행할 수 있으나 실물 자연물, 돋보기, 교사의 질문, 친구의 설명을 활용하도록 권장한다.

## 2. 개발 우선순위

### P0 — 반드시 완성할 핵심 기능

- [ ] **탐험 수첩 시작 화면**: 새 탐험, 저장한 탐험 이어하기, 교사용 수업 안내.
- [ ] **차시 안내**: `1~2차시: 관찰과 사례 탐구`, `3~4차시: 자연물×물건 결합과 표현`이 분명하게 보이되 자유 이동 가능.
- [ ] **자연 관찰 도감 8종 이상**: 자연물별 고유한 시각 자료, 특징 설명, 관찰 질문, 실제 관찰/사진 관찰 구분.
- [ ] **사진/삽화 확대 관찰**: 2~4배 확대, 관심 영역 이동 또는 부분 확대, `확대 전으로`, 모바일 핀치 제스처 대안 제공. 확대 없이도 동일 정보를 읽을 수 있어야 함.
- [ ] **관찰 수첩**: 최소 3개 자연물에 대한 모양, 무늬, 표면, 반복되는 구조, 특별한 점, 궁금증 입력. 칸은 필수 강제가 아닌 선택 입력으로 운영.
- [ ] **자연의 특별한 능력 탐구**: 자연물의 구조·기능 관계를 탐구할 수 있는 설명, 비교 질문, 관찰/예상/확인의 구분.
- [ ] **사례 연결 활동**: 자연물 4종 이상과 실제 자연 모방 사례를 연결하고, `무엇을 닮았을까?`에 대한 해설 확인. 오답 시에도 힌트·재도전 가능, 감점·등수 없음.
- [ ] **사례 도감**: 자연물, 자연의 특징, 기술 적용 방식, 일상생활 응용 분야를 구분해 표시. 관련이 입증된 사례는 근거 확인이 가능하도록 데이터 구조에 출처 정보를 둘 것.
- [ ] **자연물 × 생활용품 조합실**: 각기 다른 두 카드 묶음에서 선택, 조합 바꾸기, 무작위 조합(씨드 없어도 됨), 즐겨찾기 최소 3개.
- [ ] **조합 탐구 질문**: `자연의 어떤 특징을 가져올까요?`, `이 물건은 무엇이 달라질까요?`, `어떤 모습이 떠오르나요?` 입력.
- [ ] **상상 스케치북**: 손그림(터치/펜/마우스), 취소/다시 실행, 지우개, 전체 지우기 확인, 그림 없는 글 설명 대체 경로.
- [ ] **수첩 모아보기**: 관찰 기록·사례 탐구·조합과 스케치를 하나의 자연 탐험 수첩으로 정리.
- [ ] **A4 출력**: 인쇄 미리 보기, 페이지 넘침 방지, 불필요한 UI 숨김, 흑백 출력에서도 읽을 수 있는 결과지.
- [ ] **기기 내 자동 저장**: 새로고침 후에도 관찰 기록과 선택 사항이 유지되며, 저장 가능 여부·저장 상태를 학생에게 알림.
- [ ] **반응형 및 접근성**: 320px 모바일부터 데스크톱, 키보드만으로 학습 가능, 손쉬운 터치 조작, 설명 있는 이미지 대체 텍스트.

### P1 — 구현 권장

- [ ] 자신의 관찰 기록에 자연물 사진 1장 첨부(선택). 자동 촬영·카메라 권한 강제 금지.
- [ ] 실제 자연 사진 + 자체 제작 확대 삽화를 병렬로 제공. 확대 비교 위치 저장.
- [ ] 자연물 카드를 2장 이상 겹쳐 `자연물 + 자연물 + 생활용품` 확장 조합(기본 수업에는 노출 최소화).
- [ ] JSON으로 탐험 기록 내보내기/가져오기(기기 이동 시 활용).
- [ ] 스케치 PNG 별도 저장, 보고서 PNG/PDF 출력(브라우저 인쇄 → PDF 저장으로 대체 가능).
- [ ] 자연물 실루엣을 보면서 특징을 찾는 선택형 `관찰 퀴즈`; 정답 경쟁 없이 발견을 유도.
- [ ] 교사용 자료 탭: 학습 목표, 차시별 진행, 실물 관찰 주의, 자연물·응용 사례 검증 자료.
- [ ] 카드 인쇄: 인터넷이 불안정한 교실에서도 사용할 수 있는 자연물/생활용품 카드 PDF 또는 A4 프린트 페이지.

### P2 — 확장 선택 사항

- [ ] 현장 탐험 모드: 교내 화단 등에서 관찰한 자연물 사진을 수첩에 추가(위치정보는 저장하지 않음).
- [ ] 종이 콜라주 기능: 자연물 실루엣 SVG를 스케치에 드래그하여 배치하되, 드래그만이 유일한 방법이어서는 안 됨.
- [ ] PWA 오프라인 설치 및 캐시(외부 자산 없이도 작동하도록 구성).
- [ ] 교사가 직접 자연물/생활용품 목록을 추가하는 로컬 편집 기능.

### 구현하지 말 것

- 유료 생성형 AI API 연결, AI가 정답/발명품을 자동 만들어 주는 기능, 로그인이 필요한 서버, 학생 개인 실명 수집, 자동 위치 추적.
- 발명품의 `창의성 95점`, `실현 가능성 88점`처럼 **근거 없는 수치 평가**.
- 실물 시제품 제작, 평가표 점수, 상장·랭킹을 다음 단계 진행 조건으로 강제하는 구조.
- 11번의 가상 지도와 문제 핀, 12번의 글씨 크기·버튼 색상 조절 중심 실험 UI를 재사용하는 것.

## 3. 화면 구조와 정보 설계

### 학생 여정: '탐험 책장' 구조

```text
[표지: 자연 탐험 수첩을 펼쳐요]
             │
             ├── 1~2차시 · 자연 속으로
             │     ├─ 관찰 01: 자연 관찰 도감
             │     ├─ 관찰 02: 자세히 보기/관찰 수첩
             │     ├─ 탐구 03: 자연의 특별한 능력
             │     └─ 탐구 04: 자연을 따라 만든 물건 찾기
             │
             ├── 3~4차시 · 상상 속으로
             │     ├─ 탐구 05: 자연 모방 사례 한 번 더 살펴보기
             │     ├─ 조합 06: 자연물 × 생활용품 조합실
             │     └─ 표현 07: 나의 상상 스케치북
             │
             └── [책갈피: 나의 탐험 수첩 모아보기·인쇄]
```

- **메인 내비게이션을 카드형 대시보드로 만들지 않는다.** 실제 책의 목차처럼 양쪽에 **세로 책갈피 탭** 또는 모바일 **가로 넘김 책갈피**를 사용한다.
- 메인 화면 본문은 `한 장의 수첩 페이지`라는 개념으로 구성. 화면 좌측에는 간단한 그림/관찰물, 우측에는 직접 적는 빈 줄과 메모, 모바일에서는 위아래로 펼쳐짐.
- 시각적인 페이지 전환은 짧은 페이드/종이 넘김 느낌 정도로 제한. 모션 감소 설정을 존중한다.
- 모든 단계는 `목차로`, `이전 쪽`, `다음 쪽`, `수첩에 남기기`로 조작. 교사는 개별 단계를 바로 열 수 있다.

### 화면 0. 탐험 수첩 표지

**화면 목표:** 앱을 '미션을 완료하는 게임'이 아닌, 탐험하면서 기록하는 **개인 도감**으로 인식하도록 한다.

**시각 배치:** 크림색 도감 표지 위, 크게 그려진 식물 세밀화(나뭇잎, 솔방울, 씨앗), 구석의 작은 관찰 스탬프, 손으로 붙인 듯한 제목 라벨.

- 제목: `자연 모방 발명 연구소`
- 부제: `자세히 보면, 자연 속에 새로운 생각이 보여요.`
- 시작 질문: `솔방울은 왜 벌어질까요? 도꼬마리는 왜 달라붙을까요?`
- 선택 입력: `탐험 수첩 이름`(별명·모둠명, 실명 불필요).
- 버튼: `새 탐험 시작`, `이어 탐험하기`, `선생님 안내`.
- 진행 안내: `관찰하고 → 궁금해하고 → 실제 사례를 살펴보고 → 자유롭게 결합해 봐요.`
- 표지에 레벨·점수·캐릭터 보상이 있으면 안 됨.

### 화면 1. 자연 관찰 도감

**화면 목표:** 다양한 자연물에 오래 머무르면서 형태, 표면, 구조를 비교한다.

- 도감은 **세밀화가 들어간 자연 표본 시트** 형태. 도감 페이지 우상단에 표본 번호(`N-01` 등), 아래에 `관찰 질문`과 `관찰 메모`.
- 8종 이상 제공. `나뭇잎`, `솔방울`, `도꼬마리`, `연잎`, `벌집`, `조개껍데기`, `민들레 씨앗`, `새의 깃털`로 시작.
- 관찰물마다 적어도 2개의 관찰 포인트를 제공: 예를 들어 `표면을 자세히 보세요`, `반복되는 모양을 찾아보세요`.
- `실물로 관찰했어요` / `사진으로 관찰했어요` / `선생님이 보여 준 영상을 보았어요` 택일/복수 체크.
- `그림 확대` 버튼으로 같은 화면에서 2~4배 확대. 확대 이미지가 실제 자료 사진이 아닌 삽화라면 `확대 삽화`로 명확히 표시.
- 관찰 기록 입력은 `보이는 모양`, `표면·무늬`, `특별한 점`, `궁금한 점` 필드. 빈 항목 있어도 다음으로 이동 가능.
- **실제 관찰을 유도하는 문구:** `잠깐 화면에서 눈을 떼고, 준비한 자연물을 직접 보세요.`

### 화면 2. 자연의 특별한 능력

**화면 목표:** 관찰한 구조가 어떤 역할을 하는지 학생이 직접 추리하고, 자료와 비교한다.

- 나열된 자연물 중 1개 이상을 선택.
- 페이지를 좌우 두 구역으로 구성: `관찰한 모습` / `왜 그럴까?`.
- 입력 구분 3단계:
  1. `직접 보았거나 자료에서 확인한 내용`
  2. `나의 예상`
  3. `설명 자료를 보고 새롭게 알게 된 점`
- 학습용 원리 살펴보기:
  - 솔방울: 습도에 따라 비늘이 움직이는 현상(조건에 따라 관찰에 시간이 걸림).
  - 연잎: 표면에서 물방울이 잘 맺히고 굴러가는 현상(연잎 효과).
  - 도꼬마리: 열매의 작은 갈고리가 털·옷감 등에 걸리는 구조.
  - 벌집: 육각형이 반복되는 공간 구조.
- 원리 설명을 먼저 전부 노출하지 않는다. `내 예상 적기` 뒤에 `설명 살펴보기`를 열 수 있도록 하되, 예상 입력을 강제 잠금 조건으로 만들지 않는다.
- **주의:** 화면 안의 애니메이션/시뮬레이션이 실제 자연 현상을 정확하게 재현한 것처럼 주장하지 않는다. 사용 시 `원리를 이해하기 위한 단순화된 그림`이라고 표기.

### 화면 3. 자연 모방 사례 탐정

**화면 목표:** 자연물과 실제 기술·물건의 연결점을 찾고 근거를 설명한다.

- 왼쪽은 **자연 표본 서랍**, 오른쪽은 **생활 속 발명 사례 스크랩**. 두 영역의 소재와 색감을 구별한다.
- `연결선 긋기(드래그)`와 `두 항목 차례로 누르기(터치·키보드)` 중 하나로 연동. 드래그가 필수 조작이 되어서는 안 됨.
- 연결 기본 세트 4종:
  1. 도꼬마리 열매 ↔ 갈고리·고리 방식의 찍찍이(벨크로 원리)
  2. 연잎 ↔ 물방울을 잘 튕기는 표면 처리 기술
  3. 벌집 ↔ 육각형 벌집 구조를 응용한 경량 패널 등
  4. 솔방울 ↔ 습도에 반응하는 소재·구조의 설계 연구
- 3·4번의 경우 **원리적 응용 사례**로 안내하고, 어떤 특정 제품이 자연물에서 직접 발명되었다고 무조건 단정하지 않는다.
- 정답을 맞히면 `어떤 점이 닮았을까요?` 질문과 원리 해설. 다르게 연결했다면 `그렇게 생각한 이유를 써 보세요`로 흥미를 살리고, 실제 사례와는 구별.
- 각 사례를 `자연의 특징`, `생활 속 응용`, `공통된 원리`로 나누어 보여준다.
- 연결한 사례에서 학생이 마음에 든 것 1개를 `탐구 수첩에 붙이기`하여 저장.
- 정답 개수·시도 횟수·순위로 경쟁하지 않는다.

### 화면 4. 사례 전시 코너(3~4차시 도입에도 사용)

**화면 목표:** 다양한 자연 모방 사례를 천천히 돌아보고, 형태 모방과 기능 모방의 차이를 살핀다.

- 물건 4개 이상을 **박물관 전시 라벨과 사진**으로 소개. 상단에 `자연에서 찾은 특징 / 사람이 응용한 방법 / 닮은 점`을 명확히 표시.
- `생김새를 닮았어요`, `움직임을 닮았어요`, `기능이나 구조를 응용했어요`의 탐색용 구분을 제공하되, 실제 기술 사례에서는 여러 요소가 동시에 해당할 수 있다는 설명 추가.
- `기억에 남는 사례`, `왜 흥미로웠나요?` 선택/입력.
- 다른 학생에게 답을 확인받을 수 있는 `짝에게 설명해 보기` 안내 문구.
- 참고자료는 출처 정보를 데이터에 저장. 정식 교재 배포 시 검수된 자료를 반영.

### 화면 5. 자연물 × 생활용품 조합실 — 핵심 자유 창작 상호작용

**화면 목표:** 자연의 특징을 '바로 만들 수 있는 발명품'으로 몰아가지 않고, 기존 물건과 유연하게 연결한다.

- 책상 위에 **자연 표본 카드 1장 + 생활용품 종이 카드 1장**을 올려놓는 콜라주 구성.
- 카드를 선택하면 가운데에 겹쳐진 제목 스티커 표시: `연잎 + 우산`, `도꼬마리 + 필통`.
- 자연물 카드: 8종 이상. 생활용품 카드: 12종 이상(필통, 물병, 책가방, 우산, 신발, 연필꽂이, 휴지통, 자, 의자, 장갑, 도시락통, 책갈피 등).
- 자연물 카드를 선택할 때 해당 자연물의 `관찰한 특징`이 기존 수첩 기록에서 자동 표시되거나, 없으면 기본 특징 안내.
- 버튼: `다른 자연물`, `다른 생활용품`, `의외의 조합 뽑기`, `마음에 드는 조합 저장`, `다음 쪽: 스케치하기`.
- 조합은 실제로 **다음 스케치북 단계로 데이터가 넘어가야 한다**.
- 최소 3개 조합을 저장·비교할 수 있으나 1개만 해도 스케치 가능.
- 학생 질문 3가지:
  - `자연의 어떤 특징을 가져오고 싶나요?`
  - `이 물건의 어떤 부분이 달라질까요?`
  - `그 모습을 어떻게 표현하면 좋을까요?`
- `실제로 만들 수 있나요?` 또는 `경제성은 얼마인가요?` 같은 필수 평가 문항 넣지 않음.
- 가벼운 상상 응원 문구: `엉뚱한 조합도 괜찮아요. 자연을 새롭게 보는 눈이 중요해요.`

### 화면 6. 상상 스케치북

**화면 목표:** 최종 산출물을 실물 시제품이 아닌 **아이디어 그림과 짧은 설명**으로 만든다.

**필수 요소**

- 상단: 선택한 조합 2개 이미지/실루엣과 `연잎 + 우산` 제목.
- 선택한 자연의 특징, 생활용품 이름이 수정 가능하게 표시.
- 스케치 영역은 줄 없는 도화지처럼 넓게 제공; 흰 배경과 종이 테두리.
- 그리기: 펜 색 5~7개, 굵기 3단계, 지우개, 실행 취소, 다시 실행, 모두 지우기(확인).
- **키보드/손그림이 불편한 학생을 위한 글 설명 경로**를 동일하게 존중: `그림 없이 글로 설명하기`.
- 파일 업로드로 종이 스케치 사진 첨부 가능(P1). 촬영 강제 금지.
- 글 입력: `물건 이름`, `자연에서 가져온 특징`, `기존 물건과 달라진 모습`, `재미있다고 생각한 이유`.
- `수첩에 끼워 넣기` 버튼으로 현재 조합과 스케치를 저장.
- **금지:** AI 자동 발명 도면, AI가 학생 대신 발명품 완성, 무조건 구체적 제작 단계 작성 강제.

### 화면 7. 나의 자연 탐험 수첩 · 작은 전시회

**화면 목표:** 작성한 내용들을 도감 한 권으로 넘겨 보고, 발표나 인쇄에 활용한다.

- 순서: `표지 → 내가 관찰한 자연물 → 궁금증과 발견 → 자연 모방 사례 → 조합한 물건 → 상상 스케치 → 오늘 알게 된 점`.
- 모아보기 화면은 **한 권의 수첩을 넘기는 UI**가 중심. 데스크톱은 펼친 두 페이지, 모바일은 한 페이지씩.
- 수첩 안에 `탐험 중`인 페이지는 표시하되 빈칸이 있다는 이유로 인쇄를 막지 않음.
- 결과물 제목: `자연의 비밀을 발견한 나의 탐험 수첩`.
- 버튼: `A4 활동지로 인쇄`, `PDF로 저장(브라우저 인쇄 이용)`, `기록 내보내기`, `탐험 이어가기`.
- 발표 카드 문장 예시: `나는 ___의 ___ 특징을 발견했어요. 이 특징을 ___에 연결해 보았어요.`

## 4. 자연물 초기 데이터 및 관찰 질문

**개발 주의:** 실제 사례의 과학적 설명과 발명의 역사적 기원을 혼동하지 말 것. 아래는 **수업용 기본 관찰 데이터**이며, 대외 공개용 상세 도감 문구는 교사의 검토를 거쳐 다듬는다. 이미지가 실사 자료인 경우 적법한 라이선스와 출처를 확인한다.

| ID | 자연물 | 관찰 포인트 | 학생 질문 | 교사용 참고 특징 |
|---|---|---|---|---|
| n01 | 솔방울 | 겹겹이 포개진 비늘, 젖었을 때와 말랐을 때 형태 | 비늘은 왜 겹쳐 있을까요? 습도에 따라 무엇이 달라지나요? | 습도 조건에 반응하는 비늘의 움직임 |
| n02 | 나뭇잎 | 잎맥의 갈래, 가장자리 모양, 표면 | 잎맥은 어떤 모양으로 퍼져 있나요? | 여러 종류의 잎맥·형태 비교 |
| n03 | 연잎 | 표면의 물방울 모양, 물방울 이동 | 왜 물방울이 맺히고 잘 굴러갈까요? | 미세 구조·표면 특성에 따른 발수 현상 |
| n04 | 도꼬마리 | 열매 겉면의 작은 갈고리 | 왜 옷감이나 털에 달라붙을까요? | 갈고리 형태의 부착 구조 |
| n05 | 벌집 | 육각형이 반복되는 칸 | 왜 비슷한 모양이 반복될까요? | 반복되는 육각형 구조와 공간 구획 |

| n07 | 민들레 씨앗 | 가는 털이 퍼지는 모양 | 바람이 불면 어떻게 움직일까요? | 바람을 이용한 씨앗 퍼뜨리기 |
| n08 | 새의 깃털 | 중심 깃대와 잔가지, 깃털의 겹침 | 가벼우면서도 모양을 유지하는 이유는 무엇일까요? | 깃털의 세부 구조와 기능 |

**추가 가능 자연물:** 거미줄, 도마뱀 발바닥, 물총새 부리 등. 다만 실제 기술과 결합할 때에는 과학적 정확성을 따로 검증해 추가한다.

### 자연물 이미지·삽화 제공 기준

1. **표본 실루엣 SVG는 앱 코드에 직접 포함 가능**: 나뭇잎, 솔방울, 벌집, 연잎, 깃털 등은 직접 제작한 기초 도형 및 경로 사용.
2. 구조 확대가 중요한 자연물에는 **실제 사진 또는 출처가 확인된 확대 사진**을 추가하는 것을 권장. 사진이 없으면 `직접 제작한 개념 삽화`로 표시한다.
3. 확대 이미지를 '실제 현미경 사진'이라고 거짓 표기하지 않는다.
4. 외부 URL에 연결된 이미지는 인터넷이 끊기면 실패하므로, 사용 권한이 확보된 자산을 프로젝트의 정적 파일로 포함한다.
5. 외부 사진 자산을 확보하지 못한 경우, 핵심 UI는 자체 제작 SVG만으로 구현 가능해야 한다.
6. 실물 관찰 시 생물 보호 및 안전 수칙을 지킨다. 꺾기·채집을 당연시하지 않는다.

## 5. 기존 자연 모방 사례 데이터

아래 4종을 **필수 전시 콘텐츠**로 구현한다. `기원·적용·원리`가 다른 개념임을 디자인과 문구에서 분리한다.

| 자연물 → 응용 사례 | 자연에서 확인하는 특징 | 기술에서 참고하는 점 | 설명 시 주의 |
|---|---|---|---|
| 도꼬마리 → 찍찍이(갈고리-고리 체결) | 열매 표면의 작은 갈고리가 털·천에 걸림 | 갈고리와 고리를 이용해 붙이고 떼는 구조 | 실제 제품 구조는 자연물과 완전히 같지 않음 |
| 연잎 → 발수 표면 기술 | 표면에서 물방울이 잘 맺히고 굴러감 | 물이 퍼지거나 달라붙는 성질을 줄이는 표면 연구 | 모든 방수제품이 연잎에서 직접 발명된 것은 아님 |
| 벌집 → 허니컴 구조를 응용한 경량 재료 | 육각형 칸이 연속되는 구조 | 반복된 셀 구조를 이용한 재료·패널 설계 | 단순 모양 유사성과 실제 원리 응용을 구분 |
| 솔방울 → 습도 반응형 구조 연구 | 습도에 따라 비늘이 움직임 | 환경 변화에 반응하는 소재/구조 설계의 아이디어 | 널리 판매되는 단일 생활제품의 발명 기원처럼 단정하지 않음 |

추가 사례는 검증·출처 확보 후 확장한다. 학생이 보는 콘텐츠에는 `실제로 알려진 응용`/`함께 상상해 보는 응용` 레이블을 분명히 붙인다.

### 사례 카드 콘텐츠 예시 (필드 분리)

```json
{
  "id": "case-burdock-hook-loop",
  "natureId": "n04",
```

## 6. UI/UX 및 디자인 시스템 — 11·12번과 완전히 다른 스타일

### 6-1. 디자인 컨셉

**컨셉 이름:** `BOTANICAL FIELD NOTES` — **자연 탐험 수첩 / 식물도감 / 표본 스크랩북**

- **11번과 차별:** 마을 지도·지점 클릭·현대적 카드 패널이 아니라, **한 장씩 넘기는 자연 관찰 노트**.
- **12번과 차별:** 여러 설정을 조절하며 실시간 UI를 대조하는 실험실 패널이 아니라, **확대경·자연 표본·종이 조합·자유 스케치**.
- **분위기:** 가볍고 호기심을 자극하는 자연 관찰 탐험. 실제 과학자 필드 노트의 신뢰성과 초등학생용 수첩의 친근함을 균형 있게 담는다.
- **화면의 시각적 비유:** 표지는 진한 숲색 천 제본, 내용 페이지는 따뜻한 크림색 종이, 메모는 연필 선, 자연물은 세밀화, 사례는 스크랩된 사진과 출처 라벨.
- **금지:** 네온 그라디언트, 형광 블루/보라/핑크 대시보드, 모서리가 둥근 흰색 카드가 전면에 끝없이 나열되는 구성, 과한 3D 아이콘, 게임 UI.

### 6-2. 권장 색상 토큰

| 역할 | 색상 코드 | 용도 |
|---|---|---|
| 수첩 종이 | `#F7F0DF` | 메인 배경, 페이지 |
| 종이 밝은 면 | `#FFFCF4` | 기록 입력 영역, 인쇄 화면 |
| 제본 숲색 | `#355B45` | 큰 제목, 내비게이션, 주요 버튼 |

- 위 팔레트는 제안이며, 접근성 검수 결과 필요하면 대비를 우선하여 조정한다.

### 6-3. 서체·여백·구성

- 제목: `Noto Serif KR`, `Nanum Myeongjo`, 시스템 serif 대체. 서체 파일을 다운로드에 강제 포함하거나 유료 폰트 의존하지 않음.
- 본문: `Pretendard`, `Noto Sans KR`, 시스템 sans-serif. 본문 최소 16px 권장.
- 활동 제목은 `관찰 01`, `탐구 04`, `조합 06`처럼 **도감의 장 번호** 사용.
- 좌측 가장자리 또는 상단에는 제본 느낌의 세로선과 작은 `BOOKMARK` 책갈피.
- 파트 구분에만 얇은 식물 줄기 장식, 종이 모서리 작은 잎 아이콘을 적용. 정보 읽기를 방해하지 않음.
- 메모 입력칸은 공책 줄을 닮게 꾸미되 실제 `<textarea>`를 사용하여 접근성과 저장을 확보.
- 관찰 사진에 마우스 오버만으로 핵심 내용이 나타나지 않도록 한다.
- 모바일에서는 펼친 책을 한 페이지로 재배치하며 가로 스크롤을 만들지 않는다.

### 6-4. 핵심 상호작용의 시각 표현

**A. 확대경 모드**
- 자연물 이미지 위에 둥근 확대경 아이콘 + `자세히 보기` 버튼.
- 클릭 시 오버레이 또는 화면 내 확대 창에서 이미지 확대. 확대경이 자연물의 일부를 따라가는 효과는 선택 사항.
- 마우스뿐 아니라 터치로 위치 이동, 확대/축소 버튼, 키보드 접근을 모두 지원.

**B. 관찰 메모**
- 표본 시트 옆에 작은 펜 그림과 실제 입력 필드.
- 기록이 쌓이면 수첩 가장자리에 `관찰 기록 1`, `관찰 기록 2`라는 작은 인덱스가 나타남.
- 기록의 문장 길이 제한은 엄격하게 두지 않는다.

**C. 자연 모방 사례 연결**
- 자연물 사진과 기술 사진을 두 개의 옛 도감 페이지처럼 표시.
- 연결선은 손그림 느낌 SVG 경로로 그릴 수 있으나 기능 동작은 선택 입력으로도 가능해야 함.
- 짝을 연결할 때 `왜 닮았는지` 설명을 수첩 메모로 남기는 것이 중심.

**D. 아이디어 조합**
- 책상 위 종이 카드 두 장을 겹치고 큰 `+` 표시. 조합된 이름은 종이 테이프 라벨에 표기.
- 무작위 버튼은 `주사위`가 아니라 `새로운 조합 펼치기`로 표현.
- “추천 발명품”을 즉시 정답처럼 제시하지 말고 열린 질문과 자유 입력을 제공.

**E. 스케치북**
- 넓은 하얀 도화지, 우측에 색연필/지우개를 연상시키는 도구 막대.
- 칠판 화면이나 전문 드로잉 프로그램처럼 복잡하게 만들지 않는다.
- **취소/다시 실행과 그리기 저장**이 반드시 작동하도록 구현한다.

## 7. 4차시 수업 운영과 화면 연결

**수업은 실제 자연물 관찰이 중심이고, 웹앱은 기록과 사례 탐색을 지원**한다. 40분×2차시를 한 묶음으로 사용한다.

### 1~2차시(80분): 자연물의 특징을 관찰하고 자연 모방 발명 사례 탐구하기

| 지도안 단계 | 시간 | 교사·학생 활동 | 웹앱 활용 화면 |
|---|---:|---|---|
| 도입 | 10분 | 자연물 사진·실물 비교, 공부할 문제 확인 | 화면 0(표지), 화면 1 일부 |
| [활동1] | 25분 | 실물 자연물 관찰, 확대 관찰, 모양·구조 기록 | 화면 1(도감·관찰 수첩) |
| [활동2] | 20분 | 자연의 특별한 능력 추리, 관찰과 설명 비교 | 화면 2(구조·기능 탐구) |
| [활동3] | 15분 | 자연물과 실제 응용 사례 연결 | 화면 3(사례 연결) |
| 정리 | 10분 | 흥미로운 자연물과 사례 공유 | 화면 7 일부(수첩 모아보기) |

**공부할 문제:** `자연물의 다양한 특징을 관찰하고, 자연을 모방한 발명 사례를 탐구해 봅시다.`

> 첫 시간에 바로 아이디어 설계서로 넘기는 UI를 노출하지 않는다. 교실에서는 자연물 관찰에 충분히 몰입하도록 교사가 페이지 진행을 선택할 수 있다.

### 3~4차시(80분): 자연의 특징을 생활용품과 결합하여 아이디어 표현하기

| 지도안 단계 | 시간 | 교사·학생 활동 | 웹앱 활용 화면 |
|---|---:|---|---|
| 도입 | 10분 | 지난 시간 자연 관찰 결과 회상, 공부할 문제 확인 | 화면 7/4 |
| [활동1] | 20분 | 자연 모방 사례 추가 탐구, 형태/기능 구분 | 화면 4(사례 전시) |
| [활동2] | 20분 | 자연물+생활용품 카드 자유 조합, 조합 비교 | 화면 5(조합실) |
| [활동3] | 20분 | 마음에 드는 조합 스케치·설명 | 화면 6(스케치북) |
| 정리 | 10분 | 상상 갤러리 공유, 탐험 수첩 정리 | 화면 7(모아보기·인쇄) |

**공부할 문제:** `자연의 특징을 기존 물건과 결합하여 새로운 아이디어를 표현해 봅시다.`

**학습 부담 조절:** 관찰과 탐구만 하고 끝내도 수첩을 저장·인쇄할 수 있다. 상상 그림은 실제 완제품이 아니며, `말로 설명한 아이디어`도 동등하게 인정한다.

### 8-2. 저장 구조

- 텍스트·카드 선택·활동 데이터: 브라우저 `localStorage` 또는 IndexedDB 저장.
- 그림 파일·큰 사진: **IndexedDB Blob** 우선. 큰 PNG를 base64로 매번 `localStorage`에 기록해 저장 용량을 초과하지 않게 할 것.
- 자동 저장: 학생 입력에 맞춰 적절히 반영하고, 상태를 `저장 중...` → `이 기기에 저장했어요`로 표시.
- 새로고침해도 마지막 페이지와 입력값이 보존되어야 한다.
- 그림판의 선 데이터와 저장 미리 보기를 분리하여 취소/다시 실행이 가능해야 함.
- `처음부터 새로 시작`을 누르면 기존 활동을 삭제한다는 확인 표시 후 처리. 가능하면 JSON 백업도 제공.
- JSON 내보내기에는 `schemaVersion`을 반드시 기록하고, 가져올 때 유효성을 검사. 오류 파일로 기존 자료를 덮어쓰지 않는다.
- 실명, 학교명, 주소, 위치, 촬영 위치 메타데이터(EXIF)는 수집·출력하지 않는 방향. 학생 첨부 이미지가 허용된다면 EXIF 제거를 권장.
- 데이터가 비어 있어도 안정적으로 인쇄·탐색 가능해야 하며, 빈 항목은 `아직 기록하지 않았어요`로 표시.

### 8-3. 카드 조합 작동 규칙

1. 자연물 카드와 물건 카드 각각 하나 선택하면 조합 제목이 즉시 변경된다.
2. 처음 조합시 기존 수첩의 자연물 기록이 있으면 학생 관찰 내용을 보여준다.
3. 카드가 바뀌어도 이미 저장한 조합/스케치는 삭제하지 않는다.
4. `새로운 조합 펼치기`는 가능한 조합에서 무작위 선택하되 동일 조합이 계속 반복되지 않도록 간단히 고려.
5. 조합 저장 시 관련 자연물 ID·생활용품 ID·학생 메모를 보관한다.
6. 스케치 화면 이동 시 현재 조합 ID를 전달한다.
7. 학생이 스케치를 그리지 않고 글 설명만 작성해도 저장·출력에 문제없어야 한다.

### 8-4. 그리기 구현 기준

- Canvas 2D 또는 SVG 드로잉 중 구현 안정성이 높은 방법 선택.
- 펜/터치/마우스의 시작·이동·끝 동작을 모두 지원.
- 화면 크기 변경과 태블릿 회전 후 그림이 지워지거나 심하게 왜곡되지 않도록 한다.
- `실행 취소`, `다시 실행`, `지우개`, `모두 지우기`, `임시 저장` 실제 동작 보장.
- 터치 스크롤과 드로잉의 충돌을 막기 위해 드로잉 영역에서만 적절히 `touch-action` 관리.
- 그리기가 어려운 학생을 위해 텍스트 설명 입력을 동일 화면에 배치.

**1쪽 — 관찰 수첩**
- 탐험 제목, 모둠/별명(입력한 경우), 자연물 이름
- 선택한 자연물 2~3개의 관찰한 모양·구조·표면·궁금증
- 실제 관찰/사진/영상 구분
- 각 자연물의 소형 삽화(가능하면)

**2쪽 — 자연 모방 사례 탐구**
- 자연물 ↔ 응용 사례 연결 결과
- 자연의 특징과 기술의 응용을 설명한 학생 기록
- 인상 깊었던 사례와 이유

**3쪽 — 자연물 × 물건 조합**
- 저장한 조합들(최대 3개 우선 노출, 더 많으면 별도 페이지)
- 선택한 자연의 특징, 기존 생활용품의 바뀔 부분

**4쪽 — 나의 상상 스케치**
- 가장 마음에 든 조합, 발명 아이디어 이름
- 그림 또는 글 설명(둘 다 있으면 둘 다)
- 새롭게 느낀 점, 친구에게 소개할 한 문장

### 출력 UI/품질 조건

- 브라우저 `window.print()` 기반 실제 인쇄 가능. `@media print`에서 메뉴/내비게이션/버튼 숨김.
- A4 세로; 내용이 잘리면 자동으로 다음 페이지로 넘기고, 핵심 이미지 중간 페이지 절단 방지.
- 배경색 없이도 충분히 읽을 수 있도록 얇은 선과 글씨 위주로 출력.
- 한글 줄바꿈과 긴 학생 답변을 자연스럽게 처리, 스케치 크기 비율 유지.
- 이미지 로딩 실패 때도 문서 전체 인쇄가 중단되지 않도록 텍스트 대체.
- 교사가 필요한 경우 관찰 기록지만, 스케치지만 선택해서 인쇄할 수 있는 옵션(P1).

## 10. 권장 기술 구성

- **권장:** React + TypeScript + Vite, 또는 동등한 현대적 프런트엔드 스택. 가능하면 번들 설치 뒤 로컬에서 즉시 실행하도록 작성.
- CSS: CSS 변수 기반 테마와 자체 스타일. 대시보드 UI 프레임워크를 그대로 덧씌우지 않는다.
- 컴포넌트 분리: `NotebookCover`, `FieldNotebookLayout`, `NatureAtlas`, `Magnifier`, `ObservationEditor`, `FeatureExplorer`, `CaseMatching`, `CaseMuseum`, `CombinationDesk`, `Sketchbook`, `NotebookPrintView`.
- 데이터/로직: `natureItems`, `biomimicryCases`, `householdObjects`, `storage`, `exportImport`, `printUtils`.
- 보안: 업로드 파일의 형식·크기 검증, 사용자 입력 HTML 무해화, 타사 스크립트 최소화.
- 동작 환경: 최신 Chrome/Edge, iPadOS Safari 등 일반적인 학교 태블릿/PC 브라우저.
- 외부 이미지/폰트 서버에 의존하지 않고도 핵심 상호작용이 가능하도록 기본 자산 내장.

## 11. 기능 검수 시나리오

### 반드시 통과해야 하는 수업 시나리오

**시나리오 A — 자연물 자세히 관찰하기**
1. 앱을 열고 탐험 수첩을 시작한다.
2. 도감에서 `솔방울`을 선택한다.
3. 확대경으로 비늘 모양을 살펴본다.
4. 관찰 방식 `실물/사진/영상` 중 사용한 방식을 고른다.
5. `모양`, `특별한 점`, `궁금한 점`을 기록한다.
6. `연잎`으로 이동하여 기록하고 이전 페이지로 돌아왔을 때 솔방울 기록이 남아 있다.

**시나리오 B — 관찰과 추리 구분하기**
1. `도꼬마리`를 열어 갈고리 구조를 본다.
2. `직접 보았거나 자료에서 확인한 내용`, `나의 예상`을 각각 적는다.
3. 설명 자료를 열어 새롭게 알게 된 사실을 기록한다.
4. 인쇄 결과에서 사실/예상/학습한 내용이 구별된다.

**시나리오 C — 자연 모방 연결하기**
1. 자연물 `도꼬마리`, `연잎`, `벌집`, `솔방울`과 사례 카드를 연결한다.
2. 정답 연결과 다른 조합에 각각 적절한 피드백이 표시된다.
3. 가장 흥미로운 사례를 저장한다.
4. 새로고침 후에도 저장한 사례가 남아 있다.

**시나리오 D — 조합에서 스케치까지 이어가기**
1. 자연물 `연잎`, 생활용품 `우산`을 선택한다.
2. `물방울이 잘 굴러가는 특징을 우산에 적용해 보고 싶다`는 내용을 입력한다.
3. 조합을 저장하고 스케치북으로 이동한다.
4. `연잎 우산` 그림을 그린 뒤 실행 취소/다시 실행을 해 본다.
5. 그림 또는 글 설명을 저장한다.
6. 수첩 모아보기·출력에서 해당 조합과 그림/글이 보인다.

**시나리오 E — 발명 강요 없이 완료하기**
1. 자연물 관찰과 사례 탐구까지만 진행한다.
2. 조합과 스케치 활동은 하지 않은 상태로 탐험 수첩을 연다.
3. 완성도 경고, 강제 입력, 점수 감점 없이 현재 기록을 인쇄할 수 있다.
4. `아직 탐험하지 않은 페이지`로 표시될 뿐 오류가 발생하지 않는다.

**시나리오 F — 수업 환경 대응**
1. 태블릿에서 손가락으로 확대·메모·카드 선택·그림 그리기가 동작한다.
2. 키보드만으로 사례 연결과 카드 선택이 가능하다.
3. 모바일 폭 320px에서도 수평 스크롤 없이 주요 기능 사용 가능하다.
4. 인터넷 연결 없이 정적 자산을 불러온 상태에서 핵심 학습 기능을 수행한다(필요하면 PWA 확장).
5. 저장된 활동을 초기화하려고 하면 확인 단계가 나타난다.
6. 한국어 긴 문장, 빈 관찰 기록, 그림 미작성 상태에서도 보고서 출력이 깨지지 않는다.

### 디자인 수락 기준

- [ ] 11번의 가상 마을 지도/핀 UI가 없다.
- [ ] 12번의 옵션 조절 대시보드/점수형 비교 패널이 메인이 아니다.
- [ ] 수첩 표지, 제본형 내비게이션, 종이 느낌의 관찰 기록, 식물 세밀화, 책갈피 구성으로 **13번만의 분위기**가 명확하다.
- [ ] 자연 관찰 확대 기능이 장식이 아닌 실제로 작동한다.
- [ ] 자연물-생활용품 선택이 스케치·출력까지 데이터로 이어진다.
- [ ] 재미있는 장식보다 읽기 쉬운 글씨·분명한 버튼·편리한 조작이 우선이다.

## 12. 교사용 수업 안내(앱 내부 도움말에 포함)

**1~2차시 준비물:** 솔방울·나뭇잎·씨앗·조개껍데기 등의 안전한 자연물(확보 가능한 범위), 돋보기, 태블릿, 자연물 사진·영상. 자연물을 억지로 채집하지 않는다.

**3~4차시 준비물:** 자연물/생활용품 카드(앱 또는 인쇄본), 색연필과 종이(선택), 태블릿. 실제 발명품 제작 재료는 필수가 아니다.

**지도 시 유의할 점**
- 학생에게 “오늘 반드시 발명품을 하나 만들어야 한다”고 안내하지 않는다.
- `관찰한 사실`과 `추리한 사실`을 분리해서 말하게 한다.
- 실제 기술 사례는 학생의 상상 아이디어와 분명히 구분한다.
- 설계도나 완성품이 없는 학생도 관찰 기록과 사례 설명만으로 학습 성과를 드러낼 수 있다.
- 기기를 사용할 수 없는 상황에서는 도감 카드와 활동지 인쇄본으로 동일한 학습을 이어갈 수 있다.

**학생에게 보여 줄 마무리 질문**

- `오늘 자연에서 새롭게 발견한 특징은 무엇인가요?`
- `자연의 모습이나 움직임 중 가장 신기했던 것은 무엇인가요?`
- `자연의 특징을 다른 물건과 연결하면 어떤 재미있는 생각이 떠오르나요?`

## 13. 개발 완료 조건 및 구현 요청 요약

**이 문서를 전달받은 개발 도구/개발자에게 요청할 최종 결과물**

1. 실제 실행되는 웹앱의 전체 소스코드(필요 시 빌드 파일 포함).
2. 11·12번과 **확실히 다른 '자연 탐험 도감/수첩' 디자인**과 반응형 레이아웃.
3. 최소 8종 자연 관찰 도감, 최소 4종 자연 모방 사례, 최소 12종 생활용품 조합 카드.
4. 확대 관찰, 관찰 내용 저장, 사례 연결, 자유 조합, 스케치/글 설명, A4 수첩 출력이 모두 실제로 작동.
5. 빈 입력을 강요하지 않는 부드러운 학습 흐름, 그림을 못 그려도 참여 가능한 대체 경로.
6. 브라우저 로컬 저장 및 복구, 필요 시 JSON 가져오기/내보내기.
7. `README.md`에 설치·실행·빌드·학교 수업 사용 방법과 주의사항을 간단명료하게 정리.
8. 위 11절의 검수 시나리오를 직접 테스트하고 남아 있는 제한사항을 정확히 표시.

**마지막 강조:** 이 앱의 주인공은 발명품이 아니라 **자연을 자세히 바라보며 자신의 생각을 발견하는 학생**이다. 학습을 '발명품 완성'으로 몰아가지 말고, **관찰과 탐구를 오래 즐기는 디지털 탐험 수첩**으로 구현한다.
